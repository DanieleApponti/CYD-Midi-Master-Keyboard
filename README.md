# CYD-Midi-Master-Keyboard
display CYD mini pianoforte
Sviluppato in collaborazione con l'IA di Google 

Con un CYD WZ2432R028 si può fare una pianola midi 4 ottave con pennetta suono pianoforte
Installa e configura le librerie TFT_eSPI (con il file di configurazione per il CYD) e XPT2046_Touchscreen.
